# /handoff

User invoked **`/handoff`** or asked to hand off the session to a fresh agent. Read and follow the **`handoff`** skill (`~/.cursor/skills/handoff/SKILL.md` or project `.agents/skills/handoff/SKILL.md`).

Optional text after `/handoff` describes what the next session should focus on.

Save the handoff document to the **OS temp directory** (not the workspace). Reference specs/plans/commits by path instead of duplicating them. Include a **suggested skills** section for the next agent.

For a rich HTML “pedido vs entregue” recap in the repo, use **`/recap`** + `recap` instead.
