# Data safety no Play Console · 1.5.1

**Feito em 17/11/2026 pelo browser, conta `faruk.dev.br@gmail.com` (desenvolvedor
Faruk Zahra).** O que foi enviado está no fim deste arquivo.

O formulário de **Data safety** não tem API pública: precisa ser preenchido no
Console, em **App content → Data safety**. Este é o roteiro para o app depois do
Fale conosco com envio direto.

## O que o app faz

- Não tem conta, login, anúncios nem analytics.
- O áudio do Alcorão sai para `everyayah.com` (download), o que já existia.
- O Fale conosco manda para `api.web3forms.com` (e daí para
  `farukz@gmail.com`): o texto escrito, versão do app, versão do Android, modelo
  do aparelho e idioma.

## Respostas

1. **Does your app collect or share any of the required user data types?**
   Sim.
2. **Is all of the user data collected by your app encrypted in transit?**
   Sim (HTTPS).
3. **Do you provide a way for users to request that their data is deleted?**
   Sim. Por e-mail em `farukz@gmail.com`; a política publicada explica.
4. **Data types**
   - **Messages → Other in-app messages**
     - Collected: sim.
     - Shared: sim.
     - Processed ephemerally: não (a mensagem fica na caixa de entrada até ser
       apagada).
     - Required or optional: **optional** (só quando a pessoa escolhe enviar).
     - Purpose: **App functionality** (ler e responder). Se o Console aceitar
       mais de um, marque também **Developer communications**.
   - **App info and performance → Other app performance data** apenas se o
     formulário exigir um campo para versão do app/modelo. Não é dado de
     diagnóstico; o uso é identificar o aparelho na leitura da mensagem. Se não
     houver categoria adequada, deixe só "Messages" e mencione os campos
     técnicos na descrição da política.
5. **Não marcar**: Location (fica no aparelho), Personal info (não pedimos nome,
   e-mail, telefone), Device or other IDs (não enviamos advertising ID nem
   IMEI), Contacts, Photos, Files, Calendar, Health, Financial.

## Depois de salvar

- O resumo público do formulário passa a dizer que o app coleta "Mensagens" de
  forma opcional. É o esperado.
- Se o Google pedir revisão, a política já está publicada e cita o Web3Forms, o
  que costuma bastar.
- Rotacionar a chave do Web3Forms se aparecer spam no formulário.
