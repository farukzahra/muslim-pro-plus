## Bloqueios conhecidos

- A API do Play **não** cobre conteúdo do app, classificação, segurança de
  dados nem categoria: esses passos são só no console.
- `edits.testers` só aceita grupos do Google; listas de e-mail com endereço
  individual são criadas apenas pela interface.
- App novo só aceita release `draft` pela API até a primeira publicação.
- O console tem um diálogo de "Publicação gerenciada" e verificações rápidas
  de até 14 minutos antes de aceitar o envio.
- Browser do harness vê a tela mas não a árvore do Play Console; usar
  Playwright/CDP.
